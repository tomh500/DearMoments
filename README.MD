 # 📄 DearNextgen 使用协议与开源说明

 ## 🛠️ 一、 产品定义与核心理念
 **DearNextgen** 是一款开源的 **Counter-Strike 2** 辅助功能脚本插件。本项目的核心目标是为用户提供一套透明、可自主构建的游戏辅助体验。

 * **自主构建**：本项目完全开源，所有功能逻辑均由用户自主编译与部署，开发者不对编译后的二进制文件进行任何分发或控制。
 * **技术栈**：本产品基于游戏官方提供的控制台命令（Console Commands）、GSI（游戏状态集成）接口以及操作系统原生 API 开发。

 ## ⚖️ 二、 合规性声明
 本项目始终将游戏公平性视为开发前提：
 * **非侵入式设计**：脚本命令严格遵循 `sv_cheats 0` 的执行规范，不涉及绕过反作弊校验或修改游戏二进制核心文件。
 * **自动化行为**：部分功能涉及“输入自动化”，请用户在使用前务必评估其在特定服务器环境下的合规性。
 * **遵循准则**：本项目开发者支持 Valve 公司的 **《CS:GO Fair Play Guidelines》**，并致力于在公平竞技的框架下扩展游戏功能。

 ## 🔑 三、 开源协议与自主授权
 1. **完全自主**：本项目已转为开源项目。用户可自行从代码仓库获取、修改、编译并部署。
 2. **无需授权**：本产品不再设任何网络验证或授权机制，不存在任何形式的联网校验。
 3. **无隐私数据收集**：作为开源软件，本项目承诺**不收集、不存储、不回传**任何用户的个人数据、系统环境信息或机器码。**项目代码完全透明，用户可自行审计。**
