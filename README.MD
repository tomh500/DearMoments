 # 📄 DearNextgen 使用协议与开源说明

 ## 🛠️ 一、 产品定义与核心理念
 **DearNextgen** 是一款开源的 **Counter-Strike 2** 辅助功能脚本插件。本项目的核心目标是为用户提供一套透明、可自主构建的游戏辅助体验。

 * **自主构建**：本项目完全开源，所有功能逻辑均由用户自主编译与部署，开发者不对编译后的二进制文件进行任何分发或控制。
 * **技术栈**：本产品基于游戏官方提供的控制台命令（Console Commands）、GSI（游戏状态集成）接口以及操作系统原生 API 开发。

 ## ⚖️ 二、 合规性声明
 本项目始终将游戏公平性视为开发前提：
 * **非侵入式设计**：脚本命令严格遵循 `sv_cheats 0` 的执行规范，不涉及绕过反作弊校验或修改游戏二进制核心文件。
 * **自动化行为**：部分功能涉及“输入自动化”，请用户在使用前务必评估其在特定服务器环境下的合规性。
 * **遵循准则**：本项目开发者支持 Valve 公司的 **《CS:GO Fair Play Guidelines》**，并致力于在公平竞技的框架下扩展游戏功能。

 ## 🔑 三、 开源协议与自主授权
 1. **完全自主**：本项目已转为开源项目。用户可自行从代码仓库获取、修改、编译并部署。

 # 🛠️ DearNextgen 构建指南

 ## 1. 环境准备 (环境门槛)
 在开始构建前，请确保你的机器安装了以下环境：

 * **操作系统**：Windows 10 / 11 (64-bit)。
 * **编译器环境**：
   * **Visual Studio 2022**：必须安装“使用 C++ 的桌面开发”工作负载。
   * **核心组件**：确保在 VS Installer 中勾选 `MSVC v143 - VS 2022 C++ x64/x86 生成工具` 及 `Windows 10/11 SDK`。
 * **编程语言**：
   * **Python 3.10+**：用于驱动构建脚本。请在安装时勾选“Add Python to PATH”。
 * **核心工具**：
   * **Git**：用于拉取项目源代码。

 ## 2. 开发者能力要求 (技术门槛)
 本项目定位为开源技术研究项目，建议构建者具备以下能力：

 * **命令行操作**：熟悉 `PowerShell` 或 `CMD` 环境，能够执行构建指令。
 * **依赖排查**：项目中涉及多种 Python 库，若运行提示缺少模块（如 `ModuleNotFoundError`），请根据报错信息自行通过 `pip install <库名>` 命令进行补全。保持环境的整洁与灵活配置是开发者的必备能力。
 * **基础调试**：具备查看编译日志的能力，能定位编译器报错（如路径错误、头文件缺失等）。

 ## 3. 获取源代码
 本项目托管于 GitHub，请确保仅克隆 `OpenDear` 分支以获取离线开源版本：

 ```bash
 git clone -b OpenDear [https:github.com/tomh500/DearMoments.git](https:github.com/tomh500/DearMoments.git)
 cd DearMoments
```
 ## 4. 构建流程

 1. 环境检查与构建：
    在项目根目录运行以下命令。脚本将自动检查 VS 环境，并调用对应的编译器进行构建：
    ```powershell
    .\Build.ps1
    ```

 2. **获取产物**：
    构建完成后，所有生成的二进制文件（.exe, .dll）将自动归档至项目目录下的 `..\library\execute` 文件夹中。
