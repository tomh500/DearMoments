 # 📄 DearNextgen 用户协议

 ## 🛠️ 一、 产品定义与核心技术
 **DearNextgen**（以下简称“本产品”）是一款运用于 Valve（美国）公司旗下 **Counter-Strike 2** 游戏的脚本插件。其核心功能实现方式均采用游戏官方提供的**开发者控制台**及其**命令脚本**功能。

 本产品由以下部分组成：
 * 🎮 游戏官方提供的控制台命令及 **GSI 通信接口**；
 * 🖥️ 第三方程序（包括但不限于读取、修改、新建、删除文件）；
 * 📦 Windows 或 Linux 操作系统自带的软件包 SDK。

 ## ⚖️ 二、 合规性声明
 本产品在游戏内使用的脚本命令均**不涉及绕过游戏反作弊变量**，或者**修改未经授权的游戏核心文件**。
 * **核心目标**：旨在利用在 `sv_cheats 0` 下可以被执行的命令实现提升游戏体验的功能。
 * **自动化定义**：其中，部分脚本或程序可能涉及“**输入自动化**”的定义，从而禁止在 Valve 官方服务器上使用。
 * **遵循准则**：产品及其产品开发者严格遵循 Valve（美国）公司的 **《CS:GO Fair Play Guidelines》**，而非遵循“玩家社区约定俗成的不受任何服务器主办方或游戏官方承认的规则”（俗称“**村规**”）。

 ## 🔑 三、 使用权限与隐私说明
 1. ⚠️ **内部测试工具**：本产品仅供得到授权的人有限的使用，**禁止**以任何形式（包括但不限于 FTP、HTTP）在互联网传播本产品。
 2. 🌐 **数据收集**：在使用本产品时，产品将可能联网对用户的数据（包括但不限于**系统环境、机器码、国家或地区**）进行收集、存储、联网校验等操作。

 ## 🛡️ 四、 免责条款与主办方原则
 * **主办方权力**：在使用本产品时，应当遵循主办方原则，游戏服务器主办方有权制定游戏规则。
 * **封禁免责**：若因为本产品造成用户在第三方社区服务器的游戏账号被**冻结、封禁**，本产品开发者概不负责。

 * **官方兼容性**：本产品的开发完全符合 Valve 的公平竞技指南，且在官方服务器**尚未被明令禁止**。
