 # 📄 DearNextgen 用户协议

 ## 🛠️ 一、 产品定义与核心技术
 **DearNextgen** 是一款运用于 Valve（美国）公司旗下 **Counter-Strike 2** 游戏的脚本插件。其核心功能实现方式均采用游戏官方提供的**开发者控制台**及其**命令脚本**功能。

 安装方式如下：
 * 将项目命名为 `DearNextgen` 并放入 **cfg** 文件夹
 * 在主程序左上角文件菜单完成安装并运行必要服务后启动游戏

 ## ⚖️ 二、 注意事项
 需要获得开发者批准方可使用，目前仅对中国大陆用户开放申请，请加入我们的discord获取更多信息，[相关网站](https://tomh500.github.io/DearMoments)
